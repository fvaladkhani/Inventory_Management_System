## ✨ امکانات اصلی

### مدیریت محصولات
- 📦 **محصولات**: ثبت، ویرایش، حذف و جستجوی محصولات
- 🏷️ **دسته‌بندی‌ها**: مدیریت دسته‌بندی‌های محصولات
- 🎨 **انواع محصول**: تعریف انواع مختلف برای هر محصول (سایز، رنگ، مدل) با قیمت اضافی
- 📦 **بسته‌های محصولی**: ایجاد بسته‌های ترکیبی با تخفیف
- 🏷️ **تخفیف‌ها**: تعریف تخفیف‌های زمانی برای محصولات

### مدیریت انبار
- 📋 **موجودی**: مدیریت موجودی محصولات در انبارهای مختلف
- 📊 **تاریخچه تراکنش‌ها**: مشاهده کامل ورود و خروج کالاها
- ⚠️ **هشدار کمبود موجودی**: نمایش خودکار محصولات با موجودی کم

### سفارشات
- 📥 **سفارشات ورودی**: ثبت و مدیریت سفارشات خرید از تأمین‌کنندگان
- 📤 **سفارشات خروجی**: ثبت و مدیریت سفارشات فروش به مشتریان
- 🔄 **تأیید خودکار موجودی**: پس از تأیید سفارش، موجودی به‌طور خودکار به‌روزرسانی می‌شود
- 📌 **رهگیری سفارشات**: مشاهده تاریخچه تغییرات وضعیت سفارشات

### مدیریت طرف‌های حساب
- 👥 **مشتریان**: ثبت و مدیریت اطلاعات مشتریان
- 🏢 **تأمین‌کنندگان**: ثبت و مدیریت اطلاعات تأمین‌کنندگان
- 📞 **اطلاعات تماس**: مدیریت مخاطبین هر تأمین‌کننده

### گزارشات و تحلیل
- 📊 **داشبورد پیشرفته**: نمایش آمار کلیدی با نمودارهای تعاملی
- 📈 **گزارشات**: گزارش موجودی، فروش، خرید و تحلیل
- 📄 **خروجی PDF/Excel/CSV**: خروجی گرفتن از گزارشات
- 🖨️ **چاپ سفارشات**: چاپ فاکتورهای سفارشات

### کاربران و امنیت
- 👤 **مدیریت کاربران**: افزودن، ویرایش و حذف کاربران
- 🔒 **تغییر رمز عبور**: امکان تغییر رمز عبور کاربران
- 🛡️ **احراز هویت مبتنی بر Session**: امن و ساده

### تنظیمات سیستم
- ⚙️ **تنظیمات عمومی**: اطلاعات شرکت، واحد پول، منطقه زمانی
- 📏 **تنظیمات واحدها**: واحد وزن، ابعاد، حجم
- 🏚️ **تنظیمات انبار**: انبار پیش‌فرض، آستانه کمبود موجودی، سفارش خودکار
- 📧 **تنظیمات ایمیل**: پیکربندی SMTP برای ارسال ایمیل

### دو زبانه‌سازی
- 🌍 **پشتیبانی از فارسی و انگلیسی**: تغییر زبان به‌صورت لحظه‌ای
- 🔄 **RTL کامل**: پشتیبانی کامل از راست‌چین برای زبان فارسی
- 📝 **ترجمه کامل**: تمام بخش‌های سیستم ترجمه شده‌اند

## 🛠️ تکنولوژی‌های استفاده شده

### بک‌اند
| تکنولوژی | نسخه | توضیح |
|-----------|-------|--------|
| Laravel | 9.x | فریمورک اصلی بک‌اند |
| PHP | 8.1+ | زبان برنامه‌نویسی |
| SQLite | - | دیتابیس پیش‌فرض (قابل تغییر به MySQL) |
| Laravel Sanctum | - | احراز هویت مبتنی بر Session |

### فرانت‌اند
| تکنولوژی | نسخه | توضیح |
|-----------|-------|--------|
| React | 18.x | فریمورک اصلی فرانت‌اند |
| React Router | 6.x | مدیریت مسیرها |
| Bootstrap | 5.x | کتابخانه استایل‌دهی |
| Axios | - | درخواست‌های HTTP |
| Recharts | - | نمودارهای تعاملی |
| i18next | - | دو زبانه‌سازی |
| jsPDF / html2pdf | - | خروجی PDF |
| XLSX | - | خروجی Excel |
